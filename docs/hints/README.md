# Hint ladders

One file per milestone. Every problem has three tiers:

- **Tier 1 (nudge):** a question that points at the right idea.
- **Tier 2 (direction):** names the technique or the trap, without code.
- **Tier 3 (near-solution):** the algorithm in prose or pseudocode. Still no C++ you can paste.

Rules you agreed to:
- Try for 20 minutes before taking a tier. Take one tier at a time.
- Note in `PROGRESS.md` which tiers you used. The tutor adjusts review
  depth: if you took a tier-3 hint, expect harder questions on that code.
- The tutor may hand out a tier when you've been stuck for two rounds, but
  never skips tiers.
