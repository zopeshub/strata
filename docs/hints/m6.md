# M6 hints

## SetCurrentFile

1. Which three syscall-level steps make a file replacement atomic *and*
   durable? (You did it in lab 01.)
2. Write `"MANIFEST-%06llu\n"` into `TempFileName(dir, n)`, Sync it, Close
   it, rename it onto `CURRENT`, then SyncDir. If any step fails, remove
   the temp file and return the error. Never touch CURRENT in place.

## VersionEdit Encode/Decode

1. Deterministic encoding: in what order must the fields be emitted? (See design.md §5.)
2. Decode loop: `while (!input.empty())`: read the tag; `switch (tag)`
   parses the payload, and any `nullopt` means Corruption. Check
   `level < kNumLevels` before using it. The default case is Corruption.

## VersionSet::LogAndApply

1. What must hit disk, in what order, and what lock state do you want during that I/O?
2. Fill in `log_number`/`next_file`/`last_sequence` on the edit, and build
   the new Version (current + edit, via a builder that applies deletions
   then additions, keeping L1+ sorted by smallest). Unlock, append the edit
   to the MANIFEST, Sync, and relock. Only on success, install the new Version.
3. First call after open: create a new MANIFEST containing a snapshot of
   the whole current Version, then `SetCurrentFile`. Only one thread may
   write the MANIFEST at a time; the background thread is the only writer.
   Readers keep old Versions alive via `shared_ptr`. Obsolete files =
   (all files on disk) − (files in *every* Version still referenced).
   Tracking referenced versions: keep `weak_ptr`s, or a list pruned when expired.

## Compaction drop rules

1. Walk the merged stream. For each entry, what do you need to remember about the previous entry of the same user key?
2. Keep `current_user_key` + `last_sequence_for_key` (initially "max"). On
   a new user key, reset `last_sequence_for_key = kMaxSequenceNumber`. Drop
   when `last_sequence_for_key <= smallest_snapshot` (rule 1), or when this
   is a deletion with `seq <= smallest_snapshot` and `IsBaseLevelForKey`
   (rule 2). Then `last_sequence_for_key = this seq`.
3. `IsBaseLevelForKey(uk)`: for each level from output level + 1 to 6,
   check whether any file's user-key range contains `uk`. Keep a per-level
   cursor that only moves forward, since keys arrive in order. Output cutting:
   only between different user keys; close at `target_file_size` or at
   grandparent overlap > 10 × target.

## Orphans and missing files

1. After a crash mid-compaction, what files exist that no Version references?
2. At the end of `Open`: for every table or log file on disk that isn't
   live (and every `.dbtmp`), delete it. Before that: every file the
   recovered Version references must exist, or `Corruption`.

## CompactRange

1. "Down the tree as far as it goes": which levels overlap [begin, end]?
2. Flush the memtable first. Then, for each level from 0 to the deepest
   level with overlapping files minus 1, run a manual compaction of the
   overlapping files into the next level. Wait for each to finish.
