# ADR NNNN: <decision in one line>

- Status: proposed | accepted | superseded by NNNN
- Milestone: M<n>
- Date: YYYY-MM-DD

## Context

What problem, what constraints (correctness, performance, simplicity,
what the tests and design.md require)? 3–6 sentences.

## Options considered

1. **<option A>**: how it works; pros; cons.
2. **<option B>**: ...
3. (at least two; "do nothing / simplest thing" is often one)

## Decision

Which one, and the single most important reason.

## Evidence

Benchmark numbers (`bench/...` command + output), test results, or a
reference (paper, LevelDB/RocksDB source, man page). "It felt faster" is not
evidence.

## Consequences

What this makes easier, what it makes harder, what would make you revisit it.
